# AI WORLD｜产品总纲主文档

**副标题：一句话 / 一张照片，创造可以走进去的世界**  
**版本：v0.1**  
**日期：2026-09-15**  
**状态：持续更新主档**

> 核心原则：先做出“能走进去、想继续探索”的真实 3D 世界，再逐步叠加 AI、NPC、社交、装修、建造与商业化。

## 0. 总纲摘要

AI World 的目标不是做一个“生成 3D 模型”的工具，而是让普通用户通过一句话、一张照片、一组照片或一段视频，快速得到一个可以第三人称进入、自由走动、互动、装修、扩建、社交和游戏化的 3D 世界。

第一阶段最重要的闭环：**用户输入现实或想象 → AI 生成真实 3D 场景 → 玩家走进去 → 场景里有可交互物体、NPC、环境细节和任务 → 用户继续用自然语言修改世界。**

## 1. 产品愿景与定位

### 一句话定位
**现实和想象，都可以变成一个你能够走进去的世界。**

### 可生成范围
房间 → 房子 → 庭院 → 街区 → 社区 → 景区 → 小镇 → 城市 → 开放世界。

### 不做什么
- 不做只有“上传图片 → 一个可旋转3D模型”的工具。
- 第一版不做重型多人网络和完整经济系统。
- 不绑定单一世界模型或3D平台。
- 不先堆功能再补画质，第一版就要有环境氛围和探索感。

## 2. 产品总架构

用户输入 → 场景理解 → AI World Planner → World Scene Data → 3D环境/物体生成 → 实时运行 → 第三人称玩家 → 3D NPC / Agent → 互动/任务 → 自然语言修改世界。

## 3. 两个一级入口

### A. 一句话创造世界
例如：“给我生成一个山谷里的现代住宅社区，有湖、有咖啡馆、有很多树，我住在湖边。”

### B. Photo to World｜照片变世界
核心表达：**拍一张照片，然后走进去。**

支持真实房间、住宅、街道、社区、风景、建筑效果图、AI图、动漫/概念图、历史/童年照片。

## 4. Photo to World｜照片生成可互动 3D 世界

### 三种模式
1. **极速模式：1张图** — 娱乐、分享、AI图、概念场景；允许AI推测不可见区域。
2. **精准模式：3–8张图** — 房间、住宅、店铺；多视角约束空间。
3. **扫描模式：一段视频** — 抽帧重建；适合住宅、民宿、办公室、商铺、景区。

### 照片理解
- 场景分类
- 空间结构
- 物体识别
- 环境/材质/光照
- 可交互物体判断
- 不可见区域补全，并标记AI推测区域

### 分层生成
- **静态环境层**：地形、山体、远景、墙面、大片建筑背景、森林，可用 Gaussian Splat / World Model / 环境 Mesh。
- **可交互物体层**：门、家具、车辆、道具、植物，使用 GLB/OBJ Mesh + Collider。
- **NPC层**：3D Character + Rig + Animation + Agent。

### 房间/住宅/社区
生成后必须可以第三人称走进去。用户可直接说“把桌子换大一点”“改成奶油风”“湖边增加咖啡馆”，系统尽量只修改对应区域。

### 开放世界扩展
初始先生成高质量出生区域；玩家走向边缘时预生成相邻分区，世界逐步扩大。

## 5. 真实 3D 开放世界质量标准

- 丰富草地、花、树、灌木、岩石、水体。
- 道路、人行道、围栏、路灯、长椅、停车与生活设施。
- 建筑沿道路与功能区合理布局。
- 重点建筑可进入，室内外尺度一致。
- 天空、云、阳光、阴影、雾、风、鸟、落叶、脚步与环境声音。
- 远景完整，不能有“模型展台感”。

## 6. 第三人称玩家

**电脑**：WASD、鼠标环视、Shift冲刺、Space跳跃、E交互。  
**手机**：左摇杆、右侧镜头、跳跃、冲刺、交互。

后续增加坐下、拾取、拍照、载具、游泳。

## 7. 3D NPC / AI Agent

NPC拥有：
- 身份
- 性格
- 记忆
- 日程
- 关系
- 目标
- 路径与动作

NPC不是站桩聊天框，而是 Living World 的居民。

## 8. AI装修、建造与编辑

用户可直接说：
- 湖再大一点
- 多种花和树
- 把我家改成中式院子
- 客厅改成奶油风
- 湖边加咖啡馆
- 拓宽道路并加路灯
- 增加一个搞笑邻居

原则：局部更新，不重生成整个世界。

## 9. 社交、游戏与现实商业

### 社交
邀请好友进入；多人漫游；共同看房/作品/做任务；朋友拥有自己的社区空间。

### 游戏化
轻任务、收藏、探索、经营、建造、小游戏、UGC世界。

### 现实商业
现实房间照片 → 3D房间 → AI装修 → 走进去体验 → 家具/材料/设计师/装修/房地产/民宿酒店。

## 10. 技术路线

- 环境：Blender程序化、Gaussian Splatting、World Model
- 照片：Image-to-World、多视角/视频重建
- 物体：Hunyuan3D等 Image/Text-to-3D
- 资产：Blender + MCP/Agent
- Web：Three.js / WebGPU
- 游戏：Godot / Unity
- NPC：LLM + Memory + Behavior + NavMesh

## 11. MVP 顺序

1. M0 当前程序化3D小镇
2. M1 高质量真实3D小镇
3. M2 Photo to Room
4. M3 多图/视频精准重建
5. M4 一句话局部修改
6. M5 Living NPC
7. M6 社区与世界扩展
8. M7 多人社交

## 12. 当前原型状态

已具备：
- 山谷地形、湖泊、道路、住宅
- 可进入玩家住宅和咖啡馆
- 大量树木花草
- 第三人称走/跑/跳
- 5个3D NPC路径移动
- 找回相机任务
- 电脑/手机基础控制

当前原型是“可玩骨架”，不是最终画质。

## 13. 关键风险

- 单图不可见区域只能推测
- 多视角一致性
- Splat可编辑性差
- 高精资产/NPC性能
- 建筑与楼梯等结构合理性
- NPC持续推理成本
- 真实照片肖像和隐私

## 14. 已确定决策

- D01 真实3D可漫游，不做伪3D。
- D02 默认第三人称。
- D03 场景必须丰富且建筑规划合理。
- D04 一句话与照片生成并列一级入口。
- D05 Photo to World 支持 1图、多图、视频。
- D06 环境与可交互Mesh分层。
- D07 NPC是生活型3D Agent。
- D08 第一版小而精，再扩开放世界。
- D09 保留World Scene Data，但不让架构拖慢Demo。
- D10 底层3D模型可替换。
